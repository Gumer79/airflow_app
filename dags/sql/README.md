# SQL скрипты для BigQuery

## setup_sales_rls.sql

Скрипт для настройки Row-Level Security (RLS) для таблицы продаж.

### Как использовать:

1. Откройте [BigQuery Console](https://console.cloud.google.com/bigquery)
2. Выберите проект `shirman-group-app`
3. Создайте новый SQL запрос
4. Скопируйте содержимое `setup_sales_rls.sql`
5. Замените переменные `@@project_id`, `@@dataset_id`, `@@table_id` на свои значения
6. Выполните скрипт

### Параметры по умолчанию:

- **PROJECT_ID**: `shirman-group-app`
- **DATASET_ID**: `wildberries_raw`
- **TABLE_ID**: `sales_raw`
- **USERS_DATASET_ID**: `user_data`
- **USERS_TABLE_ID**: `users`

### Варианты реализации:

1. **Простой вариант** (рекомендуется для начала)
   - Использует подзапрос к таблице `users`
   - Просто в использовании
   - Может быть медленнее на больших объемах

2. **С таблицей-маппингом** (рекомендуется для продакшена)
   - Создает отдельную таблицу для быстрого поиска
   - Более производительный
   - Требует обновления таблицы при изменении пользователей

3. **С поддержкой администраторов**
   - Добавляет возможность для администраторов видеть все данные
   - Требует поле `is_admin` в таблице `users`

### Проверка работы:

После выполнения скрипта:
1. Проверьте, что политика создана (последний SELECT в скрипте)
2. Выполните тестовый запрос под разными пользователями
3. Убедитесь, что каждый пользователь видит только свои данные

### Удаление RLS:

Если нужно удалить RLS политику:
```sql
DROP ROW ACCESS POLICY IF EXISTS sales_rls_policy
ON `shirman-group-app.wildberries_raw.sales_raw`;
```
